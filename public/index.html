What is Shortlist?

Shortlist is a new funding discovery project from Dobriy AI. We’re starting with a curated directory of funding sources and developing tools to help users evaluate and organise relevant opportunities.

Can I apply for funding here?

Applications happen on the funding provider’s own website. Each directory link takes you to an official source, where you can review the latest calls, requirements and application process.

Which regions are covered?

The initial selection focuses on European and Austrian sources. Each programme sets its own geographic eligibility, which may include international partners. We’ll use feedback to help decide what to add next.

Can I suggest a source or share an idea?

Yes. Tell us which funding sources you use or what makes finding the right opportunity difficult. Email the Shortlist team.
