# Design assets

Shortlist uses the private Dobriy AI shared interface package, pinned to v0.1.4 in package.json and to its commit in package-lock.json. The package's landing-page profile is the design reference, with local Poppins fonts and shared colour, typography, button and wordmark styles.

The build copies the installed distribution into dist/interface-style. Generated distribution files are not committed to this repository or edited here. The bundled Poppins SIL Open Font License is served at /interface-style/fonts/poppins-OFL.txt.

The favicon is the existing Dobriy AI favicon, reused from dobriyai-site. The funding illustration is original HTML, CSS and SVG composition for this page. Funding provider names are descriptive source references, not endorsements or partnerships.
